# 👑 منصة زلزال (Zilzal Platform)
### المنصة الفاخرة للترفيه الرقمي، الألعاب المصغرة، والمجتمعات الحصرية

---

## 🌟 مميزات منصة زلزال:
1. **تصميم فاخر Dark Luxury / Cyber Gold & Neon**: تصميم أنيق وجذاب متناسق بالكامل باللغة العربية (RTL) ومتجاوب مع جميع أحجام الشاشات (هواتف، أجهزة لوحية، وكمبيوتر).
2. **شريط الإعلانات والأخبار التفاعلي**: شريط علوي متحرك وسلس لعرض الأخبار والتنبيهات، قابل للتعديل بالكامل من لوحة المدير.
3. **لوحة تحكم المدير (Admin Dashboard)**: محمية باسم مستخدم وكلمة مرور لإدارة الصور، الروابط، شريط الإعلانات، ومفتاح الذكاء الاصطناعي.
4. **نظام الزوار والدخول**:
   - **دخول سريع كزائر**: بنقرة واحدة بدون الحاجة لكتابة بريد أو كلمة سر مع 50 نقطة مجانية.
   - **إنشاء حساب رسمي**: بالبريد الإلكتروني لحفظ السكور والنقاط مع 100 نقطة ترحيبية.
   - **حساب المدير**: للوصول السريع لكافة الإعدادات.
5. **صالة ألعاب زلزال الفاخرة**:
   - 🐍 **ثعبان زلزال النيون** (مع تحكم لمس وأزرار للجوال)
   - 🚀 **صقر زلزال النفاث** (تجاوز العقبات الكهربائية)
   - 🎁 **عجلة الحظ الذهبية** (جوائز ومكافآت يومية)
   - 🧠 **تحدي بطاقات الذاكرة** (اختبار سرعة البديهة)
   - 🤖 **إكس أو الذكية** (ضد الذكاء الاصطناعي)
6. **مساعد زلزال للذكاء الاصطناعي**: شات بوت ذكي مدمج يجيب فورياً على كافة استفسارات الزوار، ويدعم ربط مفتاح Google Gemini API.
7. **عداد وتحليلات الزوار**: تتبع فوري لعدد الزيارات والزوار المتصلين وإحصائيات التفاعل.
8. **نظام صوتي مدمج**: مؤثرات صوتية حماسية ومبهرة باستخدام Web Audio API بدون الحاجة لتحميل ملفات صوتية خارجية.
